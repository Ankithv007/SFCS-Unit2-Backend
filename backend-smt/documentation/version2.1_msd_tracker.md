# SMT Manufacturing Execution System (MES)

## VERSION 2.1: MSD MOISTURE SENSITIVE DEVICE TRACKER

- **Purpose of the page:** Tracks Moisture Sensitive Devices (MSDs) floor-life exposure times to prevent component delamination during reflow.
- **What this page is used for:** Mounting components, checking floor exposure timers, recording baking actions, and monitoring critical moisture levels.
- **What has changed compared to Version 2.0:** Integrated the standardized searchable Work Order Selector.
- **What new features have been added:**
  - **Fuzzy-Searchable Work Order Selector:** Operators can type to quickly find the active Work Order ID.
- **What improvements have been made:** Dropdown responsiveness and component mounting workflow.
- **Any workflow changes:** Select target Work Orders by typing rather than scrolling.
- **Any validation improvements:** Auto-populates product details.
- **Any UI/UX improvements:** Custom combobox interface with auto-focus list.
- **Any search or filtering improvements:** Matches substring text within Work Orders.
- **Any new business rules:** Component mounting actions must be linked to active Work Orders.
- **Benefits for operators:** Easy lookup of active queues.
- **Benefits for supervisors:** Ensures moisture limits are tracked per batch.
- **Benefits for production:** Faster queue switches during component mounting.
- **Benefits for quality:** Prevents moisture-damaged components from being soldered.
- **Benefits for traceability:** Links components batch numbers directly to Work Orders.
- **Overall outcome of the changes:** Secure component shelf-life control with optimized dropdown search.
