# SMT Manufacturing Execution System (MES)

## VERSION 2.1: DOCUMENT PROCESS (QMS)

- **Purpose of the page:** Links engineering documents (BOM, PFC, XY data) to active Work Orders for operator reference.
- **What this page is used for:** Registering document process files, uploading engineering plans, auditing revisions, and referencing drawing paths.
- **What has changed compared to Version 2.0:** Integrated the standardized searchable Work Order Selector.
- **What new features have been added:**
  - **Fuzzy-Searchable Work Order Selector:** Operators can type to quickly find the active Work Order ID.
- **What improvements have been made:** Dropdown responsiveness and file-to-order mapping.
- **Any workflow changes:** Select target Work Orders by typing rather than scrolling.
- **Any validation improvements:** File extension checks (PDF, Excel, CSV, ZIP) and size verification constraints.
- **Any UI/UX improvements:** Custom combobox interface with auto-focus list.
- **Any search or filtering improvements:** Matches substring text within Work Orders.
- **Any new business rules:** Engineering document uploads must be linked to active Work Orders.
- **Benefits for operators:** Quick lookup of relevant technical plans.
- **Benefits for supervisors:** Ensures configuration controls are followed.
- **Benefits for production:** Faster queue switches during document reviews.
- **Benefits for quality:** Hardens document revision tracking.
- **Benefits for traceability:** Guaranteed correlation between drawings and target Work Orders.
- **Overall outcome of the changes:** Error-free document control with optimized dropdown search.
